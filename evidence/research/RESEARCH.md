# منظومة البحث والمكتبة والاستدلال

**الحالة:** مرجع مفاهيمي وتنظيم معرفة، لا ادعاء بناء أو تشغيل منظومة كاملة.
**الغرض:** تفسير السؤال وإثراؤه، توجيه البحث وطريقة الاستدلال، ثم حفظ ما يستحق فقط بإذن المستخدم.
**الاستبعاد:** الألعاب وصناعة الألعاب خارج النطاق ولا تُبنى عليها المكتبة.

## 1. الفصل بين الأشياء الأربعة

### Source Vault

المواد الأصلية الثابتة: المصادر والأكواد والتقارير والأرشيفات و`commits` و`hashes`. وظيفتها الحفظ والاستعادة، لا تمثيل كل ما نعرفه.

### Research Workspace

مساحة مؤقتة للمصادر والقراءات والملاحظات أثناء البحث. لا تصبح معرفة دائمة تلقائياً، ولا يلزم الإذن لإنشائها.

### Knowledge Library

مكتبة معرفة موضوعية مستقلة منطقياً عن الأرشيف. لا تدخلها إلا المعلومات التي يوافق عليها المستخدم صراحة بعد إزالة التكرار وتحديد الفائدة والمصدر ومدة الاحتفاظ.

### Research Decision Log

سجل صغير يوضح: السؤال الأصلي والمثرى، المسار المختار وسببه، طريقة الاستدلال، ما تغير بعد الاكتشافات، وسبب التوقف. ليس نصاً كاملاً للتفكير الداخلي ولا ادعاء `Chain-of-Thought`.

## 2. ما يفعله النموذج وما لا يفعله

### يفعل

- يفسر الموضوع والهدف والقيود والغموض.
- يثري السؤال بالزوايا المؤثرة والأسئلة الفرعية وما يجب استبعاده.
- يقترح مسار البحث وطريقة الاستدلال مع سبب مختصر.
- يراجع المسار بعد كل معلومة مؤثرة ويغيّره عند الحاجة.
- يعرض ما يستحق الحفظ وسبب فائدته.

### لا يفعل

- لا يجيب عن الوقائع بالتخمين.
- لا يعتبر نتيجة محرك البحث دليلاً نهائياً.
- لا يمنح نفسه صلاحية حفظ أو تنفيذ أو مشاركة.
- لا يجمع كل طرق الاستدلال في كل سؤال.
- لا يحفظ كل شيء ولا يدّعي معرفة شاملة.

## 3. مسارات البحث

| المسار | متى يستخدم؟ | الناتج المشترك |
|---|---|---|
| **الويب** | معلومة خارجية أو حديثة | مصدر واضح، تاريخ التقاط، استخراج، ربط بالموضوع |
| **المكتبة** | مصادر ومستندات موجودة | استرجاع منظم ثم قراءة الأصل وعدم الاكتفاء بالملخص |
| **البحث السابق** | منع تكرار البحث | معرفة ما تغير وما الفجوة فقط |
| **المصدر المباشر** | ملف أو رابط أو مستودع من المستخدم | مصدر أصلي وهاش واستخراج وتصنيف |
| **مزودو البيانات وAPI** | بيانات منظمة أو حديثة | مصدر وإصدار وتوقيت وحقول واضحة |
| **فهارس المعرفة الإجرائية** | سؤال «كيف أنجز؟» | طريقة أو نمط أو مثال، لا اعتباره حقيقة تشغيلية |

اختلاف المسار لا يعني مكتبات منعزلة: كل نتيجة تتحول إلى سجل معرفي موحد يمكن ربطه بالبقية.

## 4. كتالوج طرق الاستدلال

| الطريقة | متى تستخدم؟ |
|---|---|
| استرجاع مباشر | جواب صريح في مصدر |
| تفكيك | سؤال مركب يحتاج أجزاء |
| مقارنة | بدائل بمعايير مشتركة |
| سببي | البحث عن آلية السبب لا مجرد الارتباط |
| زمني | إصدارات وتغير المعلومات عبر الوقت |
| شرطي | «إذا تغير الشرط تغيرت النتيجة» |
| استقرائي | استخراج قاعدة من حالات مع التحذير من العينة |
| استنباطي | تطبيق قاعدة على حالة جديدة |
| تخميني/تفسيري | فرضيات تفسر المعطيات دون اعتبارها حقائق |
| تشابهي | نقل نمط مع ضبط الاختلافات |
| مضاد للواقع | اختبار الافتراضات والبدائل |
| احتمالي | مؤكد/محتمل/غير معروف/متعارض بلا ثقة مصطنعة |
| نقدي/عدائي | اختبار الادعاء والانحياز والتناقض |
| علاقاتي/شبكي | كيانات وروابط ومسارات معرفة |
| تصحيحي تكراري | نتيجة تكشف فجوة تغيّر الاستعلام أو المسار |
| تركيبي/منظومي | معنى جديد من جمع الأدلة والعلاقات |
| قرار تحت قيود | مفاضلة مسببة بين الجودة والوقت والتكلفة والمخاطر |

**الاختيار:** نوع السؤال + حالة الأدلة + بنية المعرفة + المخاطر. ثم تراجع الطريقة بعد أول نتيجة.

## 5. البطاقة المعرفية الموحدة

كل معلومة مرشحة للحفظ تسجل:

- `knowledge_id` و`content`.
- `type`: حقيقة، توصية، نتيجة دراسة، رأي، تجربة، غير مؤكد، طريقة.
- `subject` و`aspects`: المجال والموضوع والزاوية، لا أسماء الأدوات.
- `source_path`: ويب، مكتبة، بحث سابق، مصدر مباشر، مهارة، API.
- `source_ref`: رابط أو ملف أو commit أو مستند أصلي.
- `observed_at` و`captured_at`.
- `relations`: تدعم، تنفي، توسع، تعتمد على، تكرر، تستبدل.
- `confidence`: سبب الثقة لا رقم تجميلي.
- `license` و`content_hash`.
- `retention`: مدة الاحتفاظ وموعد المراجعة أو الاستبدال.

## 6. حالات نتيجة البحث

- **مكتملة:** الأدلة والتغطية كافية.
- **جزئية:** بعض الزوايا أُجيبت وأخرى ناقصة.
- **غير كافية:** لا أدلة كافية.
- **متعارضة:** مصادر موثوقة متعارضة ولا يحسمها التصويت.
- **متجاوَزة:** ظهرت معلومة أحدث أو نتيجة أصح.

سبب التوقف يجب أن يكون مكتوباً: اكتمال، حد أدلة، تعارض، طلب المستخدم، أو استنفاد مسار مفيد.

## 7. الحفظ والفصل عن الفعل

- الحفظ الدائم يكون بإذن المستخدم على دفعات معرفية لا على كل جملة.
- قبل الإذن: إزالة التكرار وضعف المصدر وعرض الفائدة والموضوع والمدة.
- البحث والاستدلال لا يمنحان صلاحية تنفيذ أثر خارجي.
- الحفظ أو الأتمتة أو المشاركة تمر بمسار مستقل وموافقة صريحة.
- يمكن حفظ رابط المصدر وملخصه وسبب فائدته بدلاً من المحتوى الكامل.

## 8. منع التضخم

- لا حفظ إلا لفائدة استرجاعية واضحة.
- الفهرس والعلاقات قبل تخزين نسخ إضافية.
- التحديث والاستبدال عند ظهور معلومة أحدث.
- الاحتفاظ بأصل الادعاء والاستنتاج والافتراض منفصلة.
- لا وعود بمكتبة شاملة؛ المعلومات لا سقف لها وتتوسع باستمرار.

## 9. الفجوات والنواقص المسجلة

| الفجوة | الحالة الصادقة الآن |
|---|---|
| منظومة بحث موحدة تعمل end-to-end | غير موجودة؛ المتوفر مصادر وأنماط وتصور |
| ربط السؤال بالمصدر والأداة والحالة والحدود | يحتاج استكمالاً عملياً |
| نتائج بحث عربية موثقة باسترجاع واقتباسات | غير مثبتة |
| بحث ويب بسجل مصادر واستقلال وحداثة وانحياز | غير مكتمل |
| بحث عميق يغيّر مساره بالمعطيات وسبب توقفه | غير موحد التنفيذ |
| عزل المستخدمين والمشاريع | غير مثبت في كل المكونات؛ بعض الأمثلة فيها IDOR |
| Prompt/RAG/tool poisoning | لا تغطية شاملة |
| OS sandbox وحدود المعدل والموارد | غير مكتملة |
| Langflow backend | BLOCKED بالاعتماديات؛ ليس PASS |
| Awesome examples | NOT RUN؛ أغلبها DEMO |
| Open Design full daemon | NOT RUN؛ اختبارات محددة فقط |
| نتائج خاصة مثبتة | redaction 21/21، SSRF 13/13، Ollama registry auth PASS؛ لا تعني نجاح المنظومة |
| تكامل Open Design ↔ Langflow | غير مثبت end-to-end |
| Offline/Production شامل | غير مثبت ولا معتمد |
| الصوت والفيديو والخدمات الخارجية | لم تُختبر؛ بعضها يحتاج مفاتيح أو تكلفة |
| runtime_validation_work وexpansion_work الأصليان | غير متاحين |
| سجلات الاختبارات القديمة غير المنشورة | غير متاحة |
| تاريخ Git ومحتوى submodules | غير مضمن في لقطات worktree |
| التراخيص | مختلطة؛ Self-Evolution بلا LICENSE في الجذر ومهارات تحتاج مراجعة |
| الـ132 قدرة والـ12 نطاقاً | فهرس قدرات وليس إثبات امتلاكها تشغيلياً |
| الاختبارات الحالية | ليست مطلوبة في هذه المرحلة؛ تنظيم المعلومات أولاً |

## 10. القرار التنظيمي النهائي

**سؤال ← تفسير وإثراء ← قرار مسار واستدلال ← بحث وقراءة ← مراجعة بعد الاكتشاف ← نتيجة وحالتها ← قرار مستقل لحفظها أو تجاهلها.**

مع أربع قواعد:

1. لا إجابة واقعية بلا مصدر.
2. لا حفظ دائم بلا إذن.
3. لا نتيجة بلا حالة وسبب توقف.
4. لا تراكم بلا رابط ومصدر وسياسة مراجعة.
