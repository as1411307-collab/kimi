# Style plan

- **Style name:** Integration Supplement Atlas / أطلس الإضافات.
- **Keywords:** modular, supplement, evidence, gateway, licensing.
- **Description:** A clean Arabic technical map that preserves the existing Ollama + Langflow + Open Design core and adds five clearly separated extensions. Each extension distinguishes REAL client-side material from EXTERNAL SaaS dependencies and from documentation-only references.
- **Fonts:** Noto Kufi Arabic for headings, Noto Sans Arabic for body. Repository and package names remain in English.
- **Palette:** Deep graphite `#10151D`, panels `#182230`, off-white `#F3EEE6`, muted `#9AA9B9`, purple `#B79CFF`, blue `#68B7FF`, green `#62D4A4`, amber `#F0B65B`, coral `#F08A7D`.
- **Layout:** Vertical 1080×1520. Preserved-core banner, five supplement lanes, an integration path map, and a security/license checklist. No stock images and no animation.
- **Core information:** Hermes memory/skills and OS isolation; Composio client adapters versus SaaS; TrustClaw memory/cron/rate limiting versus Vercel/remote sandbox; Helm deployment/RBAC; selected licensed skills and self-evolution documents only. Explicit NO TESTS label.
