# Style plan

- **Style name:** Blueprint Editorial / خريطة مختبر
- **Keywords:** blueprint, evidence, modular, editorial.
- **Description:** A precise dark technical atlas with four asymmetric repository cards, large evidence numbers, thin connector lines, and compact Arabic labels. It is informational rather than promotional; every claim is short and tied to the phase-one inventory.
- **Fonts:** Noto Kufi Arabic for headings and numbers; Noto Sans Arabic for body copy. Repository names remain in English.
- **Palette:** Deep ink `#0B1220`, panel `#121D2E`, soft panel `#17263A`, sand `#F4EBDD`, muted `#9DB0C7`, cyan `#51D6C7`, amber `#F0B45B`, coral `#F27D72`.
- **Layout:** Vertical 1080×1720. Strong title band, four staggered cards in a 2×2 evidence grid, a slim capability map, then a recommended-depth strip and an explicit limitation note. Right-aligned Arabic with LTR repository names and paths.
- **Core visual information:** Four repos; file counts and branch counts; each repo's best role; clear REAL/DEMO/EXT legend; no claim that the repositories form a ready-made unified system; no dedicated vulnerability-decryption suite found in main.
- **Visual elements:** Rounded panels, small repository index numerals, thin circuit-like lines, compact role badges, no stock photos, no decorative AI imagery, no animation.
